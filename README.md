This project builds a quantitative portfolio optimization system using Sharpe Ratio maximization.

## Features
- Data collection using Yahoo Finance
- Exploratory Data Analysis
- Monte Carlo portfolio optimization
- Efficient Frontier simulation
- Backtesting vs SPY benchmark
